# Gestion de Pasajes Ecuador

Estructura inicial del proyecto para la gestion de pasajes en Ecuador.

## Estado

Scaffold inicial. Las tecnologias, configuracion de ejecucion y funcionalidades estan pendientes de definicion.

## Estructura

- `frontend/`: interfaz y vistas por tipo de usuario.
- `backend/`: API, modelos, servicios y pruebas.
- `database/`: datos iniciales.
- `docs/`: arquitectura, cambios, pruebas y evidencias.
